## How much already runs on Cloudflare, and what does the management API mean?

### Takeaway

The checked-in topology puts the LB and Fresh website on Cloudflare Workers, package distribution on R2, and the Rust application plus its task service on Cloud Run with PostgreSQL on Cloud SQL. “Management API” means JSR's account, permission, catalog, and publishing logic, not Google's cloud administration API. [README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/README.md#implementation-details); [endpoint tree](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/mod.rs).

### Cited Findings

- Inspected a shallow clone of official `jsr-io/jsr` on November 8, 2026, HEAD `1624825e0783b6921e99693e10e30ae67b44119b`. All source links here are immutable. README identifies this as the source for jsr.io. Registry source is MIT, not AGPL or Apache. [README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/README.md); [LICENSE](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/LICENSE).
- LB selects API, npm, modules, or frontend by host, path, request headers, and bot rules. `api.jsr.io` and `jsr.io/api` reach the API; eligible `@scope` module requests reach R2; browser navigation reaches the frontend. Do not reduce routing to a path-only table. [Actual router](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/lb/main.ts).
- LB Terraform binds the modules/npm R2 buckets and frontend service; `REGISTRY_API_URL` is the URI of `google_cloud_run_v2_service.registry_api`. This is stronger deployment-intent evidence than an R2 label or generic Cloudflare headers. [LB infrastructure](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/lb.tf).
- Frontend Terraform deploys a Worker version with bundled JavaScript, WASM dependencies, Assets, and an LB service binding. Server-side API calls use that LB binding; browser/local calls use fetch. [Frontend infrastructure](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/cloudflare_frontend.tf); [API client](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/frontend/utils/api.ts#L190-L230).
- API dependencies are axum 0.8, Hyper 1, Tokio, SQLx with PostgreSQL. Dockerfile builds a native `registry_api` executable and runs it in a Debian image. Cloud Run receives this image plus R2 S3 endpoint/bucket configuration. S3 compatibility is an access protocol, not an execution location. [Cargo manifest](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/Cargo.toml); [Dockerfile](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/Dockerfile); [Cloud Run resources](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/cloud_run_api.tf).
- API endpoint tree nests staff admin, scopes, users, current user, authorizations, publishing tasks, tickets, and hooks. Scope router supports creation, updates, deletion, member invitation and role changes. Self-user router supports scopes, membership, accepting/declining invitations, token creation/revocation and account deletion. [API router](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/mod.rs); [scope router](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/scope.rs); [self-user router](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/self_user.rs).
- “Management” includes public reads: package/version/dependency/source/docs/score routes. `get_version_handler` explicitly queries PostgreSQL; docs handler does too. README's “not used for serving registry requests” should be read as package-install object delivery, not every HTTP read. [Package routes and handlers](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs#L149-L326); [version query](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs#L964-L1002).

### Inferences

- Distribution/data plane versus authority/control plane is useful shorthand, provided it does not erase the Cloudflare-rendered website or read-only API traffic hitting Google-hosted application logic. [LB bindings](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/lb.tf); [package router](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs).

### Gaps

- No cloud account, Terraform state, live deployment revision, logs, or DNS origin audit was available or inspected. Source/configuration establishes declared architecture, not that every checked-in change has been applied. [Inspected configuration](https://github.com/jsr-io/jsr/tree/1624825e0783b6921e99693e10e30ae67b44119b/terraform).

## What does PostgreSQL store compared with R2 metadata, and how do requests flow?

### Takeaway

PostgreSQL stores application records and relationships; R2 stores uploaded/generated files, including client-facing JSON manifests derived from registry state. Installing from the object endpoints is not the same path as browsing API-backed web pages or publishing a release. [Package schema](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230804014354_packages.sql); [manifest generation](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/publish.rs#L510-L609).

### Cited Findings

- Verified account/auth tables: `users`, `github_identities`, `gitlab_identities`, `oauth_states`, `oauth_device_states`, `tokens`, `authorizations`. Tokens contain hashes/user/type/expiry, with permissions added later; `authorizations` holds exchange tokens, challenges, approval, permissions and expiry. Do not repeat architecture.md's loose description of `authorizations` as personal access tokens: those use `tokens` with the `personal` type. [Initial users](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230720224454_init.sql); [migration directory for identity/OAuth definitions](https://github.com/jsr-io/jsr/tree/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations); [tokens](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230803181508_tokens.sql); [permissions](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230905091736_token_permissions.sql); [authorizations](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230905102152_authorizations.sql); [personal token type](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20240422122600_personal_access_token.sql).
- Sessions: login sets an HttpOnly `token` cookie; `token.rs` generates a random token and stores a SHA-256 hash. Avoid claiming these ordinary web sessions are JWTs just because architecture.md says so. [Login callback/cookie](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/auth/mod.rs#L190-L257); [token implementation](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/token.rs#L1-L56).
- Verified catalog/control tables: `scopes`, `scope_members`, `scope_invites`, `packages`, `package_versions`, `package_files`, `package_version_dependencies`, `publishing_tasks`, `npm_tarballs`. Members have `is_admin`; historical `is_owner` was removed. File rows hold path/size/checksum, not bytes. Dependency rows initially distinguish jsr and npm, so do not copy architecture.md's unsupported “node/http” table summary. [Core package schema](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230804014354_packages.sql); [admin role](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230819152708_scope_member_admin.sql); [owner removal](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230824103406_remove_scope_owner.sql); [invites](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230823140317_scope_invites.sql); [dependencies](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20231212135329_package_version_dependencies.sql); [task records](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20230811140659_publish_tasks_improvements.sql); [tarball records](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20240125155615_npm_tarballs.sql).
- Scoring facts live in `package_versions.meta`, not a `scores` table. Shared model includes README/examples/docs coverage, fast-check status, provenance flag and symbol count; API types calculate the score. Provenance endpoint verifies the attestation against the stored version-manifest digest and package repository, then stores `rekor_log_id`. No claim that complete provenance bundles live in PostgreSQL. [Meta migration](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20240222051650_scoring.sql); [model](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/crates/jsr_types/src/models.rs#L519-L531); [score calculation](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/types.rs#L350-L450); [provenance handler](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs#L1217-L1275); [Rekor column](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20240223170038_provenance_rekor_id.sql).
- Operational data includes download-count tables, `audit_logs` (plural, not architecture.md's `audit_log`), `tickets`, `ticket_messages`, `ticket_attachments`, and `email_deliveries`. [Download schemas and later aggregate](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20260404002000_optimize_package_version_indexes.sql); [audit log](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20250410110715_audit_log.sql); [support tables](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20250328065003_support_tickets.sql); [attachments](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20260822000000_ticket_inbound_email.sql); [email outbox](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/migrations/20260824120000_email_deliveries.sql).
- Five configured R2 buckets: modules, publishing, docs, npm, ticket attachments. `meta.json` contains versions/latest/yank data built from database queries; `<version>_meta.json` contains exports, manifest and module graph. [Buckets](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/buckets.tf); [metadata structures and database derivation](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/metadata.rs); [exact object keys](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/s3_paths.rs).
- Publish upload handler checks IAM, package existence/archive state, task duplication/limits, upload encoding/size and optional tarball hash restriction. It creates the task, streams upload to R2, then queues its ID; without queue configuration it spawns local background work. [Upload handler](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs#L1008-L1193).
- Cloud Run defines two services using the same `var.api_image_id`: public `registry-api` uses `--api --tasks=false`; internal `registry-api-tasks` uses `--tasks --api=false`. Cloud Tasks invokes `/tasks/publish` and `/tasks/npm_tarball_build` on the task service with an OIDC service account. These are background HTTP callbacks, not Workers or an independent queue implementation written in another language. [Services](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/cloud_run_api.tf); [queues](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/queues.tf); [task handlers](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/tasks.rs).
- Pipeline extracts/analyzes/validates input, creates npm artifact and documentation nodes, uploads files, writes version/file/dependency/npm records, uploads manifests and purges caches. Status transition distinguishes processing from manifest publication/success. Successful publish calls Algolia `upsert_package`; the symbol-indexing block is commented out. Do not claim all Algolia indexes update on every publish. [Publish state machine and finalization](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/publish.rs#L120-L609); [artifact uploads](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/tarball.rs#L614-L711).
- Current docs storage is compressed MessagePack documentation nodes (`raw.rmp.gz`), not simply pre-rendered HTML as architecture.md says. Docs request handler queries database/package/version, obtains stored nodes/context and renders HTML. Some outputs are cached. [Stored object format](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/tarball.rs#L614-L634); [path](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/s3_paths.rs#L25-L41); [HTML generation on read](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/api/package.rs#L1570-L1730).
- Outgoing mail has a Cloud Tasks queue targeting `/tasks/send_email` on task service; architecture describes Postmark delivery and email outbox/sweeper. This is outside the ordinary install path. [Queue](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/queues.tf); [email architecture](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/architecture.md#outgoing-email).

### Inferences

- “Database-backed authority, object-backed distribution” explains the duplicate use of metadata without implying a database query per installed file. It does not establish cross-service transaction semantics, instant cache freshness or outage independence. [Generated package manifest](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/api/src/publish.rs#L510-L560).

### Gaps

- No load testing, cost accounting, cache-hit measurement, live publish, production database query, or deployment was performed. Runtime success, operational spending and exact availability cannot be inferred from these files. ## Does migration code establish that the API has moved?

### Takeaway

No. A new `workers-rs` API implementation exists, but its README explicitly says it is not fronting production traffic, and the inspected LB configuration still targets Cloud Run. This is evidence of work toward a split API, not evidence of a completed migration. [Worker README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/README.md); [LB configuration](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/lb.tf).

### Cited Findings

- Worker README calls this step 4: read-only metadata GETs. It describes intended lightweight account/CRUD/auth logic through Hyperdrive and native/heavy compute remaining on Cloud Run. Checked-in entrypoint implements health, database health, stats and metrics through axum on workers-rs. [README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/README.md); [actual entrypoint](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/src/lib.rs).
- Important within-repo contradiction: README says everything else returns 501, but actual router has `.fallback(proxy_to_compute)`, forwarding remaining requests to `COMPUTE_API_URL`. Treat code as the implemented behavior, not the outdated sentence. README also references `docs/design/api-service-split.md`, which was absent from the cloned root tree, so that linked design document was not used as evidence. [README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/README.md); [fallback implementation](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/src/lib.rs#L35-L115).
- CI builds/checks this detached workspace for `wasm32-unknown-unknown`; its wrangler config is described as local development configuration, with later infrastructure work needed for production bindings/deployment. Do not confuse buildability with production traffic. [CI job](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/.github/workflows/ci.yml#L72-L101); [wrangler config](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/wrangler.toml); [README status](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/README.md#status).
- Other documentation drift: README/architecture claim highly available database; actual Terraform sets `availability_type = "ZONAL"`. Cloud SQL PostgreSQL location is verified, but do not present HA as verified deployed fact. Comments mention Hyperdrive/migration work; they do not override the LB's active configured target. [Database resource](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/db.tf); [README claim](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/README.md#implementation-details).

### Inferences

- Best current phrasing: “According to the inspected repository, Cloudflare already hosts package distribution, edge routing and the website; the authoritative application/database remain configured on Google services, with further API migration work underway.” [README](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/README.md); [LB](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/terraform/lb.tf); [migration status](https://github.com/jsr-io/jsr/blob/1624825e0783b6921e99693e10e30ae67b44119b/workers-rs/README.md#status).

### Gaps

- Actual production migration progress after this commit, uncommitted/operator-side changes, and later endpoint groups are unknown. No conclusion about acquisition strategy, future costs, speed, or full Cloudflare migration follows from this code snapshot.
